Every bot runs on RootClaw's built-in engine. Besides the [built-in providers](./index.mdx#built-in-providers), that engine can talk to any service that speaks the OpenAI chat-completions API. The old per-engine routes (OpenCode, Cline's CLI, Claude Code and Codex settings) were removed with those engines.

| Service | How |
|---|---|
| OpenRouter | Its own provider: save an **OpenRouter API key**, pick **OpenRouter** |
| Fireworks AI, DeepSeek, Cline credits, LM Studio, vLLM, anything else OpenAI-compatible | **Other (OpenAI-compatible)**, below |
| An Anthropic-compatible address | The **Anthropic** provider with a custom URL (`ROOTCLAW_ANTHROPIC_API_URL` on a server). Not tested against third-party services. |

Keys you export in your shell (`~/.zshrc`, `~/.bashrc`) don't reach the desktop app when you open it from the Dock, Finder or an app menu. Save them in Settings instead.

## Other (OpenAI-compatible)

1. Open **Settings → API keys**.
2. Paste your key into **OpenAI-compatible API key** and set
   **OpenAI-compatible base URL**:

   | Provider | Base URL |
   |---|---|
   | OpenRouter | `https://openrouter.ai/api/v1` (the default when no URL is set) |
   | Fireworks AI | `https://api.fireworks.ai/inference/v1` |
   | DeepSeek | `https://api.deepseek.com` |
   | Cline | `https://api.cline.bot/api/v1` |
   | Anything else | The OpenAI-compatible address your provider gives you, usually ending in `/v1` |

3. Press **Test**. Then pick **Other (OpenAI-compatible)** in a bot's model
   picker and choose a model.

On a server you can set `OPENAI_COMPAT_API_KEY`, `OPENAI_COMPAT_URL` and
optionally `OPENAI_COMPAT_MODEL` instead, or run
`rootclaw engine set openai-compatible --base-url URL --key-env VAR`.

To use more than one such service at once, add extra `openai-compat` instances to
`config.json` (see [Bring your own engine](https://github.com/cryptyroot-ux/RootClaw/blob/main/docs/custom-engines.md#any-openai-compatible-endpoint)).
Give each one its own key: an instance that names its own `apiKeyEnv` reads only
that key and never receives the workspace's OpenAI-compatible key.

## Free OpenRouter models

A new OpenRouter account with no credit can only use free models. Paid models
stop with "This model needs OpenRouter credit".

- **Picking one:** the model picker marks free models **(free)**. When the key
  belongs to a free account, free models that can use tools come first and
  one of them is the default. Pressing **Test** on the key says so. A model
  you chose yourself is never changed.
- **Privacy setting:** if OpenRouter's privacy settings block free models,
  turns stop with "OpenRouter's privacy settings block this free model". Allow
  free model endpoints at
  [openrouter.ai/settings/privacy](https://openrouter.ai/settings/privacy), or
  pick another model.
- **Daily limit:** OpenRouter limits how many requests free models take each
  day, and every step of a bot's turn counts as one. When the limit is used
  up, wait for it to reset or add credit at
  [openrouter.ai/credits](https://openrouter.ai/credits) to raise it.

## Current limits

One key and base URL are saved for **Other (OpenAI-compatible)** in Settings;
further services need their own instances in `config.json`. A model without
tool support needs `config.tools: false` on its instance.
