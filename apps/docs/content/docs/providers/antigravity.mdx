RootClaw no longer runs Google Antigravity, Gemini CLI or any other external agent runtime. Gemini models run on RootClaw's built-in engine through the Gemini API.

## Set up

1. Create a key in [Google AI Studio](https://ai.google.dev/gemini-api/docs).
2. Paste it as **Gemini API key** under **Settings → API keys**, or set `ROOTCLAW_GEMINI_API_KEY` in the server's environment.
3. Choose **Google Gemini** in a bot's model picker.

The Gemini API bills your Google AI account; a Google AI Pro or Ultra subscription is not used. Approvals work like every other provider: see [Approvals and inspector](../features/approvals-and-inspector.mdx).

## Moving from Antigravity

A bot that used the Antigravity engine shows its provider as unavailable. Open the bot's settings and pick a model on Google Gemini or another provider. The old Antigravity runtime and its sign-in under RootClaw's data directory are no longer used.
