RootClaw runs every bot on its own built-in (native) engine, inside the RootClaw server. It does not start an agent CLI on your computer: the external CLI and ACP engines (Claude Code, Codex, Gemini CLI, Antigravity, Cursor, Copilot, OpenCode, Cline, Kimi, Droid, Qwen, Hermes, Pi and custom ACP agents) were removed. A provider only supplies the model; tools, approvals, the shell sandbox and memory are the same whichever provider a bot uses.

## Built-in providers

Paste a key under **Settings → API keys**, or give it to the server (see [Self-hosting](#on-a-server)). Then choose the provider in a bot's model picker.

| Provider | In the model picker | Server environment variable |
|---|---|---|
| Ollama Cloud | Ollama Cloud | `ROOTCLAW_OLLAMA_API_KEY` |
| OpenAI | OpenAI | `ROOTCLAW_OPENAI_API_KEY` |
| OpenAI Responses API | OpenAI (Responses) | `ROOTCLAW_OPENAI_API_KEY` (the same OpenAI key) |
| OpenRouter | OpenRouter | `ROOTCLAW_OPENROUTER_API_KEY` |
| Anthropic | Anthropic | `ROOTCLAW_ANTHROPIC_API_KEY` (optional `ROOTCLAW_ANTHROPIC_API_URL`) |
| Google Gemini | Google Gemini | `ROOTCLAW_GEMINI_API_KEY` |
| Groq | Groq (API) | `ROOTCLAW_GROQ_API_KEY` |
| Meta | Meta Muse (API) | `ROOTCLAW_META_API_KEY` |
| xAI | xAI | `XAI_API_KEY` |
| Mistral | Mistral (API) | `MISTRAL_API_KEY` |
| Cerebras | Cerebras (API) | `CEREBRAS_API_KEY` |
| Any OpenAI-compatible API | Other (OpenAI-compatible) | `OPENAI_COMPAT_API_KEY`, `OPENAI_COMPAT_URL`, `OPENAI_COMPAT_MODEL` |

Use the `ROOTCLAW_` names. The unprefixed `OLLAMA_API_KEY`, `ANTHROPIC_API_KEY`, `GEMINI_API_KEY`, `OPENAI_API_KEY` and `META_API_KEY` are only a fallback inside the driver, used when no key is saved and the provider's default address is in use; Settings does not count them as a configured key.

A MiniMax driver also ships (`MINIMAX_API_KEY`); it is not in the default list, so add a `minimax` instance in `config.json` to use it. To reach Fireworks AI, DeepSeek or any other OpenAI-compatible service, see [Other model providers](./model-providers.mdx).

Unavailable providers stay visible with a reason (for example "No Gemini API key — open Settings → API keys.") instead of breaking the rest.

## On a server

```bash
export ROOTCLAW_OLLAMA_API_KEY=...        # any variable name works; or use --key-file FILE
rootclaw engine set ollama --key-env ROOTCLAW_OLLAMA_API_KEY
rootclaw models
```

`--key-env` is read by the CLI on your side only; the key is sent to the server and saved in `~/.rootclaw/config.json` (mode 600). Other kinds: `claude` (Anthropic), `openai`, `openrouter`, `xai`, `groq`, `mistral`, `cerebras`, `openai-compatible --base-url URL`. A variable in the server's own environment wins over a saved key and is never written to the file.

## Mistral API

Open **Settings → API keys**, save your **Mistral API key**, then choose **Mistral (API)** in a bot's model picker. The **Test** button checks catalog access without sending a chat message.

The model list refreshes from Mistral's `/v1/models` endpoint, including versioned models and aliases. Archived and non-chat models are excluded. Use **Refresh models** after new models become available to your account; an unsuccessful refresh preserves the previous list. Mistral bills requests to your API account.

For a server deployment, set `MISTRAL_API_KEY` or save `mistral.key` in the server configuration. Advanced users can declare additional `mistral` instances with a `config.model` default and endpoint URL.

## Model selection

The model picker groups models by provider and marks defaults. Providers that publish a model list refresh it from the API. Changing the model affects future turns; it does not rewrite earlier transcript history, and the bot keeps its approval level.
