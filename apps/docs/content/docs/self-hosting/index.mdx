RootClaw is local-first by default: the harness listens on loopback, bots run on its built-in engine, and application state lives under `~/.rootclaw`.

## Typical self-hosted setup

1. Run RootClaw on your personal macOS, Windows, or Ubuntu computer.
2. Give it one model provider API key (Settings → API keys, or `rootclaw engine set` on a server; see [Model providers](/docs/providers)). Use the same operating-system account for setup and the running server.
3. Add optional third-party keys only for the services you need.
4. Keep the harness on loopback.
5. Use it from other devices by pairing them: a browser, the desktop app or the phone, over a public address, your own domain or your tailnet. See [Deploy on a VPS](/docs/self-hosting/deploy-vps).

For a Linux service, the VPS guide covers [account setup](/docs/self-hosting/deploy-vps#before-you-start), [browser installation](/docs/self-hosting/deploy-vps#give-the-bots-a-browser-optional), and [unattended startup](/docs/self-hosting/deploy-vps#keep-it-running). Installing browser libraries as administrator still requires installing the browser in the service user's home. The service runs an installed, chosen release; upgrading it is an explicit step.

Stop the server before a filesystem backup. Application state under `.rootclaw` is only part of a complete backup: preserve the server's environment file (provider keys), the service user's browser state, and external workspaces too. See [Data and backups](/docs/self-hosting/data-and-backups).

## What is still third party

Self-hosting RootClaw does not self-host every optional provider:

- Model providers authenticate and bill through their own API key.
- Composio owns connected-app OAuth grants unless you replace that integration.
- Boat owns managed cloud computers.
- ElevenLabs or Fish Audio synthesizes speech when its hosted voice engine is enabled.

Apart from one model provider, these services are optional; chat needs only a provider key.

## Run headless during development

```bash
pnpm install --frozen-lockfile
pnpm dev:server
```

The main harness listens on `127.0.0.1:8799` by default. Keep it private; it owns agent processes, approvals, computers, and workspace configuration.
