## Connect a model provider

RootClaw runs every bot on its built-in engine, so there is no agent CLI to install. It needs one model provider with an API key.

1. Open **Settings → API keys** (the welcome asks for one too).
2. Paste a key for a provider such as Ollama Cloud, OpenAI, OpenRouter, Anthropic or Google Gemini, then press **Test**.
3. Open the model picker. Configured providers appear normally; unconfigured ones explain what is missing.

See [Model providers](../providers/index.mdx) for the complete list and the server environment variables.

## Using RootClaw at work

If your company uses RootClaw Admin, you can sign in with your organization to use the AI models it provides, alongside your own. It is optional. See [Use RootClaw at work](./organisation.mdx).

## Build from source

Requirements: Node.js 24 or newer, pnpm 10.33.0, and an API key for one model provider.

```bash
git clone https://github.com/cryptyroot-ux/RootClaw.git
cd RootClaw
corepack enable
pnpm install --frozen-lockfile
```

Run the harness, web UI, and Electron shell in separate terminals:

```bash
pnpm dev:server
pnpm dev
pnpm dev:desktop
```

## Where data lives

RootClaw stores its application data under `~/.rootclaw`. Electron window and browser data use the normal per-platform application data directory.
